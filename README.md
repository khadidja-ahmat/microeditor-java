# Microeditor JavaFX

Projet d'architecture logicielle : micro éditeur de figures géométriques.

## Objectif
Ce projet consiste à réaliser un mini éditeur de dessin vectoriel permettant :
- d'ajouter des figures depuis une toolbar
- de grouper et dégrouper des figures
- de modifier leurs propriétés
- de gérer undo/redo
- de sauvegarder et charger un document
- de sauvegarder l'état de la toolbar

## Technologies
- Java
- JavaFX
- Git / GitHub

## Architecture prévue
Le projet est organisé en plusieurs packages :
- `model`
- `command`
- `factory`
- `observer`
- `persistence`
- `ui`

## Design patterns envisagés
- Composite
- Command
- Observer
- Factory
